Лаунчер проекта MIDWAY. Основной файл — **MIDWAY.exe**.

Текущая версия **2026.11.20.3000**. Номер установленного лаунчера виден слева. Нажмите на него, чтобы проверить обновления программы.

Выберите карточку своего сервера, PvE или PvP. У каждого сервера свой список модов в Яндекс Облаке. Кнопка ручной загрузки находится под выбором папки SCUM. При повторном запуске MIDWAY проверяет зашифрованный кэш и докачивает изменённые или отсутствующие паки.

При первом переходе MIDWAY может предложить сохранить найденные старые паки wildmods с расширением `.pak.midway-backup`. Перенос происходит с согласия игрока после проверки новой загрузки. Если в папке есть неизвестный или изменённый мод, лаунчер укажет его имя.

Если появляется ошибка D3DCOMPILER_43.dll, установите [официальный Microsoft DirectX End-User Runtime](https://www.microsoft.com/en-us/download/details.aspx?id=35). Для работы виртуальных паков нужен WinFsp. Лаунчер предложит установить его, если компонент отсутствует.

Обновления MIDWAY распространяются через этот репозиторий. Если прежняя версия не обновляется автоматически, скачайте MIDWAY.exe по ссылке выше. Оба манифеста содержат одну версию и контрольную сумму. Старые имена SCUM_Official_Launcher.exe и DUNE_Launcher.exe сохранены для совместимости ссылок. Оба файла идентичны MIDWAY.exe. Настройки прежних установок поддерживаются.

У MIDWAY.exe пока нет Authenticode-подписи издателя. SHA-256 файла указан в релизе.
