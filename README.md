## Запуск и обновление

Скачайте MIDWAY.exe и откройте его при закрытой игре. Эта версия содержит и загрузчик, и игровой модуль; устанавливать базовую версию 3000 не нужно. В уже установленном MIDWAY подтвердите обновление либо нажмите номер версии в верхней панели.

Если совместимый WinFsp отсутствует, лаунчер предложит подтвердить установку в Windows. Официальный WinFsp 2.2.26323 встроен в EXE, проверяется по SHA-256 и устанавливается тихо без мастера и автоматической перезагрузки. Если Windows потребует перезагрузку, выполните её перед запуском игры. Повторная установка совместимого WinFsp не требуется.

Выберите папку установленной SCUM, нажмите «Запустить игру» и выберите PvP или PvE. Моды скачиваются с Яндекса и проверяются. Ручная загрузка позволяет подготовить зашифрованный кэш заранее. Оставьте MIDWAY открытым до выхода из SCUM: после завершения игры виртуальные моды отключаются.

При первом переходе со старых модов MIDWAY может предложить сохранить прежние PAK с суффиксом `.pak.midway-backup`. Перенос выполняется после проверки скачивания и с согласия игрока.

## Исправления 3005

Исправлены отказ после оставшейся пустой папки подключения без записи владельца и ошибка при различии регистра букв в пути Windows. Папки с файлами сохраняются. Пути библиотек Steam приводятся к фактической папке перед подключением и запуском игры. При других ошибках отображаются этап и причина, подробности сохраняются в журнале лаунчера.

Модуль подключения теперь поставляется в каждом обновлении. Сохраняются проверка подписанного каталога, SHA-256 модов и ускоренная докачка из версии 3003.

Проверено без запуска SCUM: подготовка и подключение обоих профилей по 79 модов, контрольные суммы зашифрованных файлов и открытого содержимого, штатное отключение; 27 проверок Python и 5 проверок восстановления папки. Игровой сеанс и установка драйвера на чистой Windows в этот прогон не входили.
