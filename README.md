MIDWAY 1.0.5 (обновление старого лаунчера: 2026.11.22.3015).

На скриншоте игрока установлена конкретная причина остановки загрузки: invalid peer certificate: UnknownIssuer. HTTPS-соединение с GitHub отклонялось проверкой цепочки сертификатов.

Загрузка модов, обновлений и данных сайта переведена на штатный TLS Windows (Schannel). Вместо копирования корневого хранилища для отдельного валидатора используется системная проверка цепочки доверия. Метаданные обновлений Tauri также используют этот механизм. Проверка издателя сертификата, имени узла и срока действия сохранена; небезопасные режимы принятия любых сертификатов не включались. SHA-256 модов и подпись обновлений по-прежнему обязательны.

Неразрешённый издатель больше не вызывает повторный полный цикл получения тех же ссылок. На главном экране показывается понятное сообщение, полная техническая причина остаётся в журнале.

Проверки перед публикацией: локальный HTTPS-сервер с временным CA, доверенным только отдельному тестовому клиенту; отказ недоверенному CA, неверному имени узла и истёкшему сертификату; реальные полные комплекты PvP/PvE, распаковка, SHA-256 и установка в отдельные тестовые папки; сохранение настроек при обновлении EXE. Сертификаты в хранилище Windows не устанавливались. Реальную SCUM не запускали.

Если на конкретном компьютере сама Windows не может подтвердить сертификат, лаунчер продолжит отклонять соединение. Доступ к компьютеру игрока отсутствует, поэтому результат исправления у него отдельно не подтверждён. При невозможности автоматического обновления новый MIDWAY.exe можно скачать вручную по ссылке релиза.
