# MIDWAY 1.0.8

Старый лаунчер получает обновление **2026.11.22.3018**, Rust 1.0.0 — **1.0.8**.

MIDWAY 1.0.8 — моды обновляются отдельно от лаунчера.

При запуске и перед загрузкой/проверкой модов MIDWAY получает актуальный список всех PAK из последнего опубликованного GitHub Release выбранного сервера: PvE или PvP. Добавление, замена и удаление модов больше не требуют пересборки или обновления EXE. Устанавливаются только изменённые файлы; прежние проверенные файлы используются повторно.

Владелец добавляет PAK в Assets текущего релиза нужного репозитория. Замена файла с тем же именем обновляет его у игроков. Удаление PAK из релиза убирает его из управляемого набора после успешной загрузки и проверки замены. Если создаётся новый релиз, он должен содержать полный комплект модов; черновики и предварительные релизы игрокам не выдаются. Для замены названия модификации старый PAK нужно убрать из релиза — два разных имени считаются двумя отдельными модами.

Проверяются размер и SHA-256, предоставленные GitHub по HTTPS. Токен GitHub в клиенте отсутствует. ZIP мелких модов используется только при полном совпадении всех его файлов с актуальным списком. Сбой GitHub, незавершённая загрузка, некорректный или пустой каталог останавливают операцию и сохраняют установленный комплект.

Это одно обновление лаунчера для перехода на новый механизм. Дальнейшая публикация PAK в GitHub Release не требует изменения номера версии MIDWAY, ручного редактирования JSON или подписи каталога владельцем.

Проверены добавление/замена/удаление с неизменной сборкой движка, разделение PvE/PvP, более 100 файлов с пагинацией, неполные загрузки, сбои HTTP и устаревший ZIP. Живой запрос GitHub обнаружил 80 PAK в каждом текущем профиле, сохранив все прежние пути и контрольные суммы. Игровой процесс SCUM при этих проверках не запускался.
