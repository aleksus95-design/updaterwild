# MIDWAY

Текущая версия **2026.11.20.3009** — обычная загрузка модов без шифрования.

[Скачать MIDWAY.exe](https://github.com/aleksus95-design/updaterwild/releases/download/launcher-2026.11.20.3009/MIDWAY.exe)

По просьбе владельца восстановлена работа лаунчера на базе 2900. Моды скачиваются обычными PAK с GitHub; WinFsp, Яндекс и выдача ключей не требуются. Новый номер 3009 позволяет обновиться с 3008 и обеих прежних веток лаунчера.

Закройте игру и предыдущий лаунчер, затем подтвердите обновление или скачайте EXE выше. Выберите папку SCUM, нажмите «Запустить игру» и выберите PvP/PvE. Доступны ручная загрузка, удаление модов и выбор сохранения модов в игре. Язык игры остаётся выбранным игроком.

## Файлы модов

В EXE встроен полный каталог текущих **79 клиентских PAK**. У каждого файла проверяются размер и SHA-256; недокачанный или повреждённый комплект не допускается к запуску. Сохраняются докачка и параллельная загрузка.

[Обычный клиентский комплект](https://github.com/aleksus95-design/updaterwild/releases/tag/midway-plain-client-20261120). Аккаунт GitHub и API-ключ игроку не нужны. Репозиторий wildmods остаётся закрытым. Серверные архивы, исходники модов и ключи не входят в эту публикацию.

Каталог закреплён за этой сборкой. Изменение состава модов потребует публикации нового комплекта и обновления лаунчера. Прежний зашифрованный кэш и установленный WinFsp не удаляются; эта версия их не использует.
