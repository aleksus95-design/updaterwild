## Как обновиться

Текущая версия **2026.11.20.3004**. Откройте MIDWAY при закрытой игре и подтвердите «Обновить». Для ручной проверки нажмите номер версии в верхней панели. После перезапуска там появится v2026.11.20.3004.

Ускорена докачка последнего медленного пака. MIDWAY подключает освободившиеся соединения к оставшимся частям файла и проверяет SHA-256. Нижняя строка отдельно показывает получение ссылки, загрузку и проверку файла на диске. Готовые паки сохраняются в кэше.

При запуске MIDWAY проверяет совместимость WinFsp с игровым модулем. Если WinFsp отсутствует или установлена старая версия 2.1, встроенный официальный WinFsp 2.2.26323 устанавливается или обновляется после подтверждения Windows. Установка тихая, без отдельной загрузки и без автоматической перезагрузки. Совместимая версия повторно не устанавливается. Исправлена подготовка WinFsp для случая TypeInitializationException при несовпадении версий SDK 2.2 и DLL 2.1. Исправления скорости загрузки из версии 3003 сохранены.

Выберите PvE или PvP. Кнопка ручной загрузки под выбором папки SCUM скачивает зашифрованные паки из Яндекс Облака. Общий прогресс меняется с первых полученных байтов. Уже проверенные файлы используются из кэша. Кнопка «Играть» подключает моды выбранного сервера.

При штатном обновлении с версии 2026.11.20.3000 MIDWAY сохраняет её игровой модуль. Для первой установки на новом компьютере начните с [базовой версии](https://github.com/aleksus95-design/updaterwild/releases/download/launcher-2026.11.20.3000/MIDWAY.exe) и примите обновление. Если вы уже скачали новый EXE напрямую, при входе в игру можно выбрать базовый MIDWAY.exe. Для чтения виртуальных модов нужен WinFsp 2.2. При запуске MIDWAY устанавливает или обновляет его из встроенного проверенного установщика после подтверждения Windows. Если установка отменена, можно продолжить ручную загрузку модов; для игры нужен совместимый WinFsp.

Отдельный загрузчик также доступен. [Скачать MIDWAY-Download-Fix.exe](https://github.com/aleksus95-design/updaterwild/releases/download/launcher-2026.11.20.3000/MIDWAY-Download-Fix.exe)

При первом переходе MIDWAY может предложить сохранить старые паки wildmods с расширением `.pak.midway-backup`. Перенос выполняется с согласия игрока после проверки загрузки.

Если появляется ошибка D3DCOMPILER_43.dll, установите [официальный Microsoft DirectX End-User Runtime](https://www.microsoft.com/en-us/download/details.aspx?id=35). WinFsp 2.2 включён в MIDWAY.exe. Если Windows попросила перезагрузку после установки, перезагрузите компьютер и откройте MIDWAY снова.

Обновления MIDWAY распространяются через этот репозиторий. Если прежняя версия не обновляется автоматически, скачайте MIDWAY.exe по ссылке выше. Оба манифеста содержат одну версию и контрольную сумму. Старые имена SCUM_Official_Launcher.exe и DUNE_Launcher.exe сохранены для совместимости ссылок. Оба файла идентичны MIDWAY.exe. Настройки прежних установок поддерживаются.

У MIDWAY.exe пока нет Authenticode-подписи издателя. SHA-256 файла указан в релизе.
