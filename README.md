# MIDWAY 1.0.6

Исправлена обработка заблокированного файла при обновлении лаунчера.

- При временном отказе Windows в доступе обновлятор ждёт освобождения EXE до 20 секунд и повторяет атомарную замену. Контроль хэша, подписи и резервная копия сохраняются.
- Несколько работающих копий одного EXE обнаруживаются перед перезапуском: нужно закрыть лишние окна, процессы принудительно не завершаются.
- После неудачной попытки показывается причина; автоматическое окно того же обновления не повторяется. Повторную попытку можно вызвать нажатием версии.
- Успешное открытие интерфейса подтверждается независимо от проверки локального кэша. Ошибка кэша не вызывает возврат старого лаунчера.
- При следующих обновлениях используется подписанный помощник из новой сборки.

Если 1.0.4/1.0.5 зациклилась с «Отказано в доступе», закройте все окна MIDWAY, скачайте новый EXE в отдельную папку (например, Загрузки\MIDWAY-1.0.6) и запустите именно этот файл. Исправление в новой версии не может изменить уже работающий обновлятор старого EXE. Не требуется отключать антивирус. Моды и настройки игры не удаляются.
