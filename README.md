# SCUM Official Launcher

Публичные сборки и канал автообновления SCUM_Official_Launcher.

- [Скачать последнюю версию](https://github.com/aleksus95-design/updaterwild/releases/latest)
- [BattleMetrics](https://www.battlemetrics.com/servers/scum/41110508)
- [Голосование](https://wargm.ru/server/82004/votes)
- [Магазин](https://wargm.ru/server/82004/shop)

Подключение: `92.38.222.26:7014`.

В версии **2026.09.08.1700** исправлены вылеты кнопок в нативной сборке. Если старая версия закрывается при нажатии «Проверить лаунчер», [скачайте исправленный EXE](https://github.com/aleksus95-design/updaterwild/releases/latest/download/SCUM_Official_Launcher.exe) и замените старый файл. Удалять настройки и данные игры не нужно.

Основной код новых сборок компилируется в нативный модуль. Это затрудняет восстановление исходного кода, но не запрещает копирование ресурсов или общедоступных игровых модов.

Статистика BattleMetrics (название, онлайн, состояние и ранг) читается с публичной страницы и обновляется каждые 60 секунд. Для этого используется Microsoft Edge WebView2 Runtime с отдельным служебным профилем, без доступа к личным данным браузера. При отсутствии Runtime его можно установить с [сайта Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/).

При недоступности BattleMetrics используется резервный источник с явной подписью. Ранг BattleMetrics при этом недоступен; устаревшие числа не выдаются за текущий онлайн. Подробности изменений и ограничения проверки указаны в описании релиза.
