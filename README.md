# MIDWAY — SCUM Launcher

Публичные сборки MIDWAY и канал автообновления SCUM_Official_Launcher.

- [Скачать последнюю версию](https://github.com/aleksus95-design/updaterwild/releases/latest)
- [Голосование](https://wargm.ru/server/82004/votes)
- [Магазин](https://wargm.ru/server/82004/shop)

Подключение: `109.248.4.18:7020`.

Версия **2026.09.10.1240**: адрес сервера изменён на **109.248.4.18:7020** для запуска игры, проверки ожидаемого подключения, отображения и копирования IP.

Оформление MIDWAY сохранено: фон и эмблема проекта, графитовые панели и оранжевые акценты. Запуск, голосование, магазин и управление модами собраны в нижней панели; центральная область с артом свободна. Размер окна — 1220×700.

**BattleMetrics полностью удалён**: нет статистики, фоновых запросов, таймеров или встроенного браузерного модуля. WebView2 для лаунчера больше не нужен.

Сохранены RU/EN/ZH, копирование IP, настройки игроков, пути загрузки модов и автообновление. Имя файла SCUM_Official_Launcher.exe оставлено для совместимости. Пройдены 26 тестов для исходника и нативного модуля, smoke-тесты, самопроверка EXE и визуальная проверка трёх языков. Реальная игра при проверке не запускалась.

Если старая версия закрывается при нажатии «Проверить лаунчер», [скачайте новый EXE](https://github.com/aleksus95-design/updaterwild/releases/latest/download/SCUM_Official_Launcher.exe) и замените старый файл. Удалять настройки и данные игры не нужно.

Основной код новых сборок компилируется в нативный модуль. Это затрудняет восстановление исходного кода, но не запрещает копирование ресурсов или общедоступных игровых модов.

Authenticode-подпись издателя отсутствует. Подробности изменений и ограничения проверки указаны в описании релиза.

Оба манифеста обновления и оба корневых EXE (основной и совместимый со старым именем DUNE_Launcher.exe) относятся к одной сборке. Исходники и личные файлы разработчика в этот репозиторий не публикуются.

Существующая синхронизация может удалять сторонние .pak/.sig в SCUM/Content/Paks. Моды других серверов храните отдельно. Записи в UserChoice и изменения прав реестра в коде лаунчера не обнаружены.
