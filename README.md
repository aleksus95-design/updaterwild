## Источник загрузки

В меню **«Загрузка»** под кнопкой ручной загрузки доступны:

- **Авто** — сначала GitHub; при ошибке или обрыве переключается на Яндекс. При последующем сбое доступен обратный переход. Скачанная часть файла сохраняется, если источник поддерживает докачку.
- **GitHub** — скачивание файлов только с GitHub.
- **Яндекс** — скачивание файлов только с Яндекса.

Выбор запоминается. Проверенный зашифрованный кэш общий; повторно скачивать исправные моды не нужно. Проверки подписанного каталога и SHA-256 сохраняются. При ошибке DNS Windows лаунчер пробует защищённый DNS Cloudflare/Google только для адресов служб загрузки; настройки Windows и проверка HTTPS-сертификатов сохраняются. При исчерпании попыток или неполном комплекте запуск игры останавливается с ошибкой.

Каталог, временные ссылки и разрешения расшифровки пока выдаёт Yandex Cloud Functions. Переключение источника файлов не устраняет полную недоступность этой службы. GitHub-аккаунт или API-ключ игроку не нужен.

## Запуск и обновление

Подтвердите обновление в лаунчере либо скачайте MIDWAY.exe по ссылке выше при закрытой игре. Выберите папку установленной SCUM, нажмите «Запустить игру» и выберите PvP или PvE. Оставьте MIDWAY открытым до завершения SCUM: после выхода виртуальные моды отключаются.

Официальный установщик WinFsp 2.2.26323 встроен в EXE. При отсутствии совместимого WinFsp лаунчер просит подтверждение Windows и устанавливает его без мастера и автоматической перезагрузки. Если Windows потребует перезагрузку, выполните её перед игрой.
