Подключение: `109.248.4.18:7020`.

Версия **2026.09.12.1545**: проверка D3DCOMPILER_43.dll до запуска SCUM, новый Discord и исправления автоматического перезапуска после обновления. Ссылки магазина/голосования, IP сервера, дизайн и настройки сохранены.

Если появляется ошибка **D3DCOMPILER_43.dll**, установите [официальный Microsoft DirectX End-User Runtime](https://www.microsoft.com/en-us/download/details.aspx?id=35). Лаунчер покажет окно со ссылкой Microsoft и кнопкой повторной проверки. Наличие DirectX 12 не заменяет эти дополнительные библиотеки. Отдельные DLL с посторонних сайтов скачивать не нужно; установка компонентов требует действия игрока.

Новая версия больше не завершает установщик через 1,2 секунды и не удаляет его резервные файлы. Установщик самостоятельно подтверждает устойчиво открытое окно MIDWAY; системное окно ошибки не считается успехом. Повторная установка заблокирована на время передачи управления, первая отрисовка не ждёт очистки старых файлов.

MIDWAY: иконка M, окно 1120×640, качественный фон без обрезки, полоса статуса в самом низу. Окно обновления выполнено в графитово-оранжевом стиле MIDWAY.

Исправлены скачок прогресса назад, повторный запуск установки, перевод этапов обновления и восстановление старого EXE при сбое. Запуск нового окна после обновления больше не ждёт ответа GitHub. RU/EN/ZH, настройки игроков, пути модов и адрес подключения сохранены. BattleMetrics отсутствует.

Для обновления нажмите «Проверить лаунчер». Старые версии устанавливают **MIDWAY.exe**. При первом переходе старый установщик ещё может иметь прежнее оформление; следующие обновления из MIDWAY используют новый дизайн. Если прежний лаунчер не обновляется, скачайте MIDWAY.exe вручную. Настройки и игру удалять не нужно. Старые ярлыки при необходимости перенаправьте на MIDWAY.exe.

Оба манифеста обновления относятся к одной версии и контрольной сумме. Старые имена SCUM_Official_Launcher.exe и DUNE_Launcher.exe в корне репозитория, а также совместимый EXE в релизе сохранены только для старых ссылок. Их содержимое идентично MIDWAY.exe. Служебные имена каталогов настроек сохранены для совместимости существующих установок.

Пройдены 51 тест исходников и те же 51 тест нативной сборки, smoke-тесты, самопроверка EXE и проверка интерфейсов RU/EN/ZH. Замена и запуск настоящего EXE проверены в изолированной папке для MIDWAY.exe и старого имени SCUM_Official_Launcher.exe. В этом тесте скачивание заменено локальным пакетом, дочерний EXE работает в режиме самопроверки. Реальная игра не запускалась, системные компоненты автоматически не устанавливались.

Исходники и личные файлы разработчика не публикуются. Основной код компилируется в нативный модуль, но это не делает ресурсы неизвлекаемыми. Authenticode-подпись издателя отсутствует.

Синхронизация может удалять сторонние .pak/.sig в SCUM/Content/Paks. Моды других серверов храните отдельно. Реестр UserChoice и его права лаунчер не изменяет.
