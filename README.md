MIDWAY 1.0.3 (обновление старого лаунчера: 2026.11.22.3013).

Исправлен ложный индикатор «0 КиБ / 0 КиБ, 0/0», который появлялся при наличии скачанных файлов и оставался во время проверки и установки. Лаунчер показывает текущий этап: проверка скачанных файлов, поиск прежних модов, список загрузки, скачивание, распаковка, проверка целостности и установка. При проверке показаны имя файла и счётчик. Основные этапы записываются в журнал.

Убраны полные повторные чтения всех PAK при обновлении интерфейса. Если первоначальная проверка установила, что весь комплект уже скачан, повторная подготовка загрузки пропускается. Перед установкой и запуском целостность по-прежнему проверяется. Общий ZIP проверяется один раз при составлении списка загрузки. Длительные операции с диском выполняются в рабочем потоке. Пауза при подготовке не сбрасывается перед скачиванием.

Проверено реальное анонимное скачивание из обоих публичных репозиториев: по 48 файлов (весь архив из 47 модов и один крупный PAK с загрузкой частями), распаковка, SHA-256, установка в отдельную тестовую папку и повторная проверка без скачивания. Регрессионные проверки: отсутствующий установленный PAK восстанавливается из проверенной скачанной копии; повреждённый файл того же размера требует скачивания; пауза прекращает подготовку. Системные и сетевые тесты включают разрыв соединения и продолжение загрузки.

Это исправление подтверждённого дефекта подготовки и отображения. Не установлена причина остановки на конкретном компьютере игрока: по одному скриншоту её нельзя отличить от долгой проверки диска. Реальную SCUM и вход на игровой сервер при проверке не запускали. Полный комплект из 79 файлов не скачивался повторно в этой проверке; предыдущее испытание всех 79 файлов обоих репозиториев сохранено отдельно.
