# SCUM Official Launcher

Публичные сборки и канал автообновления SCUM_Official_Launcher.

- [Скачать последнюю версию](https://github.com/aleksus95-design/updaterwild/releases/latest)
- [BattleMetrics](https://www.battlemetrics.com/servers/scum/41133084)
- [Голосование](https://wargm.ru/server/82004/votes)
- [Магазин](https://wargm.ru/server/82004/shop)

Подключение: `92.38.222.26:7020`.

Версия **2026.09.09.1130** переводит подключение на порт 7020 и BattleMetrics 41133084, усиливает проверку статистики и сохраняет исправления вылетов кнопок нативной сборки. Пройдены 42 теста для исходника и нативного модуля, smoke-тесты и самопроверка EXE. Реальная игра при проверке не запускалась.

Если старая версия закрывается при нажатии «Проверить лаунчер», [скачайте новый EXE](https://github.com/aleksus95-design/updaterwild/releases/latest/download/SCUM_Official_Launcher.exe) и замените старый файл. Удалять настройки и данные игры не нужно.

Основной код новых сборок компилируется в нативный модуль. Это затрудняет восстановление исходного кода, но не запрещает копирование ресурсов или общедоступных игровых модов.

Лаунчер запрашивает статистику BattleMetrics (название, онлайн, состояние и ранг) раз в 60 секунд. Для публичной страницы используется Microsoft Edge WebView2 Runtime с отдельным служебным профилем, без доступа к личным данным браузера. При отсутствии Runtime его можно установить с [сайта Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/).

**Ограничение проверки 9 сентября:** публичная страница и виджет BattleMetrics возвращали программным запросам HTTP 403. Новый ID привязан, но получение живой статистики в этой сети не подтверждено. Ошибка статистики не блокирует запуск игры и копирование IP. Для стабильной интеграции нужен разрешённый доступ к сервису; ключи API не встраиваются в EXE.

При недоступности BattleMetrics используется резервный источник с явной подписью. Ранг BattleMetrics при этом недоступен; устаревшие числа не выдаются за текущий онлайн. Подробности изменений и ограничения проверки указаны в описании релиза.

Оба манифеста обновления и оба корневых EXE (основной и совместимый со старым именем DUNE_Launcher.exe) относятся к одной сборке. Исходники и личные файлы разработчика в этот репозиторий не публикуются.

Существующая синхронизация может удалять сторонние .pak/.sig в SCUM/Content/Paks. Моды других серверов храните отдельно. Записи в UserChoice и изменения прав реестра в коде лаунчера не обнаружены.
