MIDWAY 1.0.4 (номер для прежнего лаунчера: 2026.11.22.3014).

Исправлено нестабильное отображение онлайна PvP. В 13 последовательных ответах сайта за три минуты предыдущие сроки актуальности трижды истекали за 3–8 секунд до следующего запроса. Теперь учитывается задержка импорта серверного журнала: свежесть счётчика ограничена 180 секундами от исходного измерения и 90 секундами от наблюдения источника. Успешный HTTP-запрос не продлевает возраст старого счётчика.

Одиночная ошибка сети не переводит ещё свежие данные в устаревшие. При действительном истечении срока показываются «Последние данные», максимум 10 минут от исходного измерения; при отсутствии подтверждённых данных показывается «нет данных». Свежий ответ сайта с явным offline сразу убирает старый счётчик, нулевой реальный онлайн сохраняется как 0.

PvP и PvE опрашиваются отдельными запросами: зависание одного источника не задерживает другой. Переиспользуется HTTPS-клиент, добавлена одна ограниченная повторная попытка при ошибке запроса.

Проверены воспроизведение прежнего мигания на записанных ответах настоящего сайта, отсутствие мигания с новым расчётом, потеря сети, восстановление ответа, возраст данных, неверный адрес, настоящий нулевой онлайн и явный offline. Сохранены исправления подготовки модов 1.0.3, прямого запуска SCUM 1.0.2 и подготовки WebView2 1.0.1.

Реальная игра в этих тестах не запускалась. Конкретная причина отсутствия скачивания у игрока не установлена без версии и журнала с его компьютера; предыдущая проверка реального скачивания и установки 48 файлов из каждого репозитория прошла.
